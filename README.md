# My Portfolio Website

A simple, no-build-tools portfolio site — just HTML, CSS, and JavaScript.

## How to run it (easiest way)

1. Unzip the folder.
2. Double-click `index.html`.
3. It opens in your browser. That's it — no install, no server needed.

## How to edit it

- **Your name, projects, bio, email:** open `index.html` in any text editor (Notepad, VS Code, etc.) and change the text.
- **Colors, fonts, spacing:** open `style.css` — the colors are defined at the top under `:root` so you can change them in one place.
- **Mobile menu behavior:** `script.js`.

## Files

- `index.html` — the page content
- `style.css` — all the styling
- `script.js` — mobile menu toggle
- `README.md` — this file
